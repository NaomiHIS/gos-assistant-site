📥 Скачать дамп
Скачает файл gos-dump-YYYYMMDD.sql с полным содержимым БД: структура + все данные. Формат совместим с mysql < file.sql.
Внимание: файл содержит все пароли пользователей (хешированные), их email, HWID устройств и другие чувствительные данные — храни в защищённом месте.

⚠ Опасно! Импорт полностью перезапишет текущую БД. Все существующие данные будут заменены содержимым файла. Сделай экспорт текущей БД сначала!

Ручной ввод
Скопируйте текст с форума (Ctrl+A → Ctrl+C) и вставьте сюда. Формат: Статья 1.1 — Название, описание, Наказание: ..., Звёзды розыска: N. Поддерживаются части (1.1 ч.1, 1.1 ч.2) — они импортируются как отдельные статьи.

AI-настройки
Конфигурация AI-провайдера для ассистента (Premium-фича). Значения сохраняются в БД и подхватываются без рестарта сервера.
Провайдер
OpenAI-совместимый endpoint. Примеры: https://api.vsegpt.ru/v1, https://api.openai.com/v1, https://api.proxyapi.ru/openai/v1.
Текущий: —. Оставьте поле пустым, чтобы сохранить остальные настройки не трогая ключ. Введите пробел или прочерк и очистите поле, потом нажмите «Очистить ключ» ниже, если хотите сбросить.
Идентификатор модели у выбранного провайдера. Например: google/gemini-3.1-flash-lite, gpt-4o-mini, gpt-5-nano.
Параметры генерации
Лимит длины ответа. Дефолт: 2000. Слишком мало → обрезается перечисление статей.
0 — детерминированно, 1 — креативно, 2 — хаос. Для правового ассистента 0.1–0.3.
Скользящее окно 1 час, ключ = user.id. Дефолт: 60.
Состояние
—
Env-переменные (AI_API_KEY, AI_API_BASE_URL, AI_MODEL, AI_MAX_TOKENS, AI_TEMPERATURE, AI_RATE_LIMIT_PER_HOUR) продолжают работать как fallback — используются если соответствующее поле в БД пустое.
